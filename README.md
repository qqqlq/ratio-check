# RatioCheck

写真の上に黄金比・三分割などの格子線（ガイド）を重ねて構図を分析するローカルツール。写真は外部に送信されません。

## 起動

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # dist/ に静的ファイルを出力
```

### Tailscale経由で使う

```bash
./start.sh          # ポート変更: ./start.sh 9000（既定 8766）
```

ビルド済みの `dist/` を `serve.py` で配信します（必要なら自動でビルド）。待ち受けるのは **`127.0.0.1` と Tailscale のIP(100.x)だけ**で、`0.0.0.0` では待ち受けません。LANや外部ネットワークには公開されず、tailnet内の端末からだけ `http://100.x.x.x:8766` で使えます。

## できること

- 写真の読み込み（ファイル選択・ドラッグ&ドロップ・貼り付け）
- ガイドの追加：生成ガイド（三分割／黄金分割グリッド／対角線／中心十字／黄金三角形／黄金螺旋／黄金長方形）と、`public/guides/` の透過PNG（黄金比01〜10・白銀比）
- ガイドの移動・拡縮（Shiftで自由変形）・回転（Shiftで15°刻み）・左右上下反転・不透明度・線色・太さ、複数重ね・並べ替え・ロック
- 注釈：メモ／円／四角／矢印／線
- 写真のモノクロ化・明るさ調整（構図を見やすくする）
- 重ねた状態を元解像度で PNG/JPEG ダウンロード（「写真を含める」オフで透過PNGのガイドのみも可）
- Undo/Redo

### ショートカット

`V` 選択 / `H` 移動 / `T` メモ / `O` 円 / `R` 四角 / `A` 矢印 / `L` 線
`Ctrl+Z` 元に戻す / `Ctrl+Shift+Z` やり直し / `Ctrl+D` 複製 / `Delete` 削除 / 矢印キー 微調整 / ホイール ズーム / Space+ドラッグ パン

## ガイドPNGの追加

`public/guides/` にPNGを置き、`src/guides.ts` の `PNG_GUIDES` に1行追加。線は黒など単色の透過PNGを想定（表示時に選択した色へ着色されます）。
