# 001 初期実装

## 何をしたか
- Vite + React + TypeScript で SPA を構築（`src/`）
- 描画は Canvas に統一（`src/render.ts` の `drawScene`）。画面表示と書き出しで同じ関数を使うため、見たままの状態で保存される
- 生成ガイドは `src/guides.ts` の `drawGen` でコード描画。黄金螺旋は正方形を左→上→右→下の順に切り出して四分円を連結
- PNGガイドは `source-in` で単色に着色して描画（LRUで6枚までキャッシュ）
- `ratio/` の元PNGを `public/guides/` にコピーして同梱（元ファイルは未変更）
- 操作：`Stage.tsx` にヒットテスト、ハンドル（拡縮・回転）、ズーム/パンを実装。`App.tsx` にライブラリ・レイヤー・設定パネル・Undo/Redo・書き出し

## なぜしたか
- 構図分析のため、黄金比等のガイドを写真に自由に重ね、重ねた状態を保存したい
- PNGだけでなく生成ガイドも用意し、色・太さ・反転・回転を自由に変えられるようにした
